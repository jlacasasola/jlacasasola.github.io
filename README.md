# 🌐 jlacasasola_es — Curriculum Web en Castellano

Página web personal en forma de currículum vitae, construida con tecnologías web modernas y diseñada para presentar de forma clara y atractiva la experiencia profesional, habilidades y proyectos.

---

## ✨ Características

- Diseño limpio, responsivo y accesible
- Navegación fluida entre secciones
- Presentación estructurada de experiencia, formación y habilidades
- Optimizado para dispositivos móviles y escritorio
- Preparado para ser desplegado de forma sencilla

## 🚀 Instalación y uso

```bash
# Clonar el repositorio
git clone https://github.com/jlacasasola/jlacasasola_es.git

# Acceder al directorio
cd jlacasasola_es

# Abrir en el navegador (si es HTML estático)
open index.html
```

Si el proyecto usa un servidor de desarrollo:

```bash
npm install
npm run dev
```
